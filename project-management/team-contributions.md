# CCAMS Team Contributions

## Project
Campus Clinic Appointment Management System (CCAMS)

## Team Structure

| Member | Responsibility |
|---|---|
| Member 1 | Project Coordination and Documentation |
| Member 2 | Authentication and Security |
| Member 3 | Database and Appointment Management |
| Member 4 | Frontend and UI/UX |
| Member 5 | Testing and Notifications |

## Collaboration Guidelines

1. Each member must use their own GitHub account.
2. Each member must work on their assigned Git branch.
3. Members must commit their own contributions.
4. Changes must be submitted through pull requests.
5. Contributions must be reviewed before merging into the main branch.
6. All members must test their work before submission.

## Project Coordinator

Responsible for coordinating tasks, monitoring progress, managing documentation and reviewing project contributions.
